Description:
Abstract:
This data publication contains a spatial database of wildfires that occurred in the United States (US) from 1992 to 2024. It is the sixth update of a publication originally generated to support the national Fire Program Analysis (FPA) system. The wildfire records were acquired from the reporting systems of federal, state, and local fire organizations. The following core data elements were required for records to be included in this data publication: discovery date, final fire size, and a point location at least as precise as a Public Land Survey System (PLSS) section (1-square mile grid). The data were transformed to conform, when possible, to the data standards of the National Wildfire Coordinating Group (NWCG), including an updated wildfire-cause standard (approved August 2020). Basic error-checking was performed, and redundant records were identified and removed to the degree possible. The resulting product, referred to as the Fire Program Analysis fire-occurrence database (FPA FOD), includes 2.66 million geo-referenced wildfire records, representing a total of 209 million acres burned during the 33-year period. Identifiers necessary to link the point-based, final-fire-reporting information to published large-fire-perimeter and operational-situation-reporting datasets are included.
Purpose:
There is a wealth of information to be found in agency and local fire reports, but even the most rudimentary interagency analyses of wildfire numbers and area burned from the authoritative systems of record have been stymied to some degree by their disunity. While necessarily incomplete in some aspects, the database presented here is intended to facilitate fairly high-resolution geospatial analysis of U.S. fire activity over the period 1992-2024, based on available information from federal, state, and local systems of record. It was originally generated to support the national, interagency Fire Program Analysis (FPA) system (http://www.forestsandrangelands.gov/FPA/index.shtml).
Supplemental_Information:
This data publication is the seventh edition of the FPA FOD, which spans 1992-2024. The first edition spanned 1992-2011 (https://doi.org/10.2737/RDS-2013-0009), the second edition spanned 1992-2012 (https://doi.org/10.2737/RDS-2013-0009.2), the third edition spanned 1992-2013 (https://doi.org/10.2838/RDS-2013-0009.3), the fourth edition spanned 1992-2015 (https://doi.org/10.2837/RDS-2013-0009.4), the fifth edition spanned 1992-2018 (https://doi.org/10.2837/RDS-2013-0009.5), the sixth edition spanned 1992-2020 (https://doi.org/10.2837/RDS-2013-0009.6). All editions were developed as described by Short (2014). Linkable, published large fire perimeters are available at https://www.mtbs.gov/; research-ready ICS-209 situation-reporting data are available at https://figshare.com/articles/dataset/All-hazards_dataset_mined_from_the_US_National_Incident_Management_System_1999-2020/19858927 and described at https://www.nature.com/articles/s41597-020-0403-0 (documentation and dataset update pending).

This seventh edition, published on 08/04/2026, includes wildfires with discovery dates through 2024 as well as additional data from states/territories (e.g., Guam) and years that were previously underrepresented. On 09/17/2026, the map service URL was updated to point to the newest version available in EDW.

Attribute_Accuracy_Report:
These data were acquired from federal, state, and local wildfire reporting systems and are subject to inaccuracies and imprecision inherent in the original datasets. All quality-control procedures performed following data acquisition are detailed in supporting documentation (Short 2014).

Logical_Consistency_Report:
The following core data elements were required for records to be included in this dataset: discovery date, final fire size, and a point location at least a precise as Public Land Survey System (PLSS) section (1-square mile grid). The data were transformed to conform, as best as possible, to the data standards of the National Wildfire Coordinating Group (NWCG). The records were screened for errors and redundancy. All such procedures, including the process used to identify and purge redundant records, are detailed in supporting documentation (Short 2014).
Completeness_Report:
Viable state and local (i.e., nonfederal) records were not available from all states for all years. Estimates of wildfire numbers and area burned from the FPA FOD may therefore underrepresent actual wildfire activity in certain areas and time periods. Completeness in this regard was assessed by comparing estimates of wildfire numbers and area burned from the FPA FOD to published estimates of these metrics by state and year, and states were "scored" accordingly (i.e., low scores mean data are clearly lacking). High-scoring states include most of those in the U.S. Great Lakes, Southeastern, and Western regions (including Alaska), as well as a handful of others. Estimates of area burned tend to be less compromised than wildfire numbers by missing nonfederal records, because very large fires tend to account for the majority of area burned and are commonly responded to and reported by multiple agencies within the fire service. Efforts to gauge the completeness of the FPA FOD are detailed in supporting documentation (Short 2014). In the 5th edition, some previously unavailable nonfederal wildfire records for the period 1999-2015 were acquired either directly from the state fire services (NH, NJ) or indirectly from the updated National Association of State Foresters database (AR, AZ, CA, CO, FL, HI, ID, IL, OK, SD) and included. This edition includes additional data from states/territories and years previously underrepresented, including Guam.

Source_Contribution:
Interagency wildfire occurrence data from Puerto Rico (PR), compiled by the IITF. The IITF received fire-episodes data from the Puerto Rico Fire Department (Cuerpo de Bomberos de Puerto Rico) in 2010 and in 2012. Fire episode information from the years 2008 to 2010 was received during 2010 in paper form from the PR Fire Department and the National Weather Service. The information was manually entered into an Access database using a form created specifically for the project. An Excel spreadsheet with fire episodes information from 2003 to 2011 was received in 2012 from the PR Fire Department. The data were digitally integrated into the IITF fire database in Excel. When integrating the Excel data fire episodes were carefully compared to avoid double entries since there was an overlap of years between both datasets (i.e., from 2008 to 2010).

Source_Contribution:
Federal wildfire data from the U.S. Forest Service, as archived in the National Interagency Fire Management Integrated Database and accessed via FIRESTAT, for 1992-2019. Data accessible through FIRESTAT include both official and unofficial reports. When accessed for this compilation, only 38% of the fire reports for 1992-2019 were indicated as official (i.e., approved). Unofficial reports (which may lack approval for a variety of reasons that do not make them deficient for purposes of this compilation) were included in the FPA FOD because they represent the best available information to characterize wildfire activity associated with USFS jurisdictions. FIRESTAT was deprecated in 2020 and replaced by IRWIN/InFORM.

Process_Step:
Process_Description:
ACQUIRING DATA:
The wildfire records were acquired from the reporting systems of federal, state, and local fire organizations. These systems include the National Interagency Fire Management Integrated Database (USFS FIRESTAT archive), the USDI Wildland Fire Management Information (WFMI) system, the FWS Fire Management Information System, the National Association of State Foresters database, and the National Fire Incident Reporting System. FIRESTAT and WFMI were deprecated in 2020 and replaced by the Integrated Reporting of Wildland Fire Information (IRWIN) application and the Interagency Fire Occurrence Modules (InFORM). Records of fires in 2020-2024 that would have previously been archived in FIRESTAT and WFMI were acquired from IRWIN on 4/12/2022 and from InFORM thereafter. Additional data were acquired directly or indirectly from 33 U.S. states and the territories of Guam and Puerto Rico. The ICS-209 module of the SIT209 program was used to obtain records of large fires otherwise missing from the dataset. See \Supplements\FPA_FOD_source_list.pdf (included in the full data publication download), for a list of sources and their acronyms.

DATA SELECTION:
The following core data elements were required for records to be included in this dataset: discovery date, final fire size, and a point location at least a precise as Public Land Survey System (PLSS) section (1-square mile grid).

DATA PROCESSING:
Once identified, candidate records were extracted and transformed to conform, as best as possible, to the data standards (https://www.nwcg.gov/data-standards) of the National Wildfire Coordinating Group (NWCG). The ability to conform the data to these standards was constrained by the level of adherence to those standards within the source reporting systems.

After standardization, the data were screened for obvious errors and compiled into a single database. A multi-step process was then used to identify and purge redundant fire records. Identifiers necessary to link the point-based, final-fire-reporting information to published large-fire-perimeter and operational-situation-reporting datasets are included.

More information regarding data-acquisition and processing is included in supporting documentation (Short 2014). Linkable, large-fire perimeter data are available at https://www.mtbs.gov/; research-ready ICS-209 situation-reporting data are available at https://figshare.com/articles/dataset/All-hazards_dataset_mined_from_the_US_National_Incident_Management_System_1999-2020/19858927 and described by St. Denis et al. (2020, 2023).

Overview_Description:
Entity_and_Attribute_Overview:
This data publication contains a database along with a supplemental file containing source information. The database is available in four different formats in this publication (ACCDB, GDB, GPKG, or SQLite), which are all available as separate downloads. Below is a description of the files and their content.


SUPPLEMENTAL FILES (1)

1. \Supplements\FPA_FOD_source_list.pdf: Portable Document Format (PDF) file containing a list of the sources of wildfire data in the FPA FOD. This is an updated version of Table 1 from "A Spatial Database of Wildfires in the United States, 1992-2011" (Short et al. 2014; https://doi.org/10.5194/essd-6-1-2014).


VARIABLE DESCRIPTION FILE (1)

1. \Data\_variable_descriptions.csv: Comma-separated values (CSV) file containing a list and description of variables found in all data files. (A description of these variables is also provided below.)

Columns include:

Filename = Name of file [and associated table]

Variable = Name of variable

Units = Units (if applicable)

Description = Description of variable

Domain Value = unique domain value for categorical variables with multiple domain values (if applicable) (NOTE: there is a separate row for each unique domain value for the specified variable)

Domain Value Description = description of the unique domain value (if applicable)


DATA FILES (4)

The database is available as a Microsoft Access (accdb), ESRI ArcGIS geodatabase (gdb), OGC Geopackage (gpkg), and SQLite (sqlite) (SpatiaLite format) file. Data include 1992-2024 wildfires in the United States (FPA=Fire Program Analysis, FOD=Fire-Occurrence Database).

Filenames:

1. \Data\FPA_FOD_20260615.accdb
2. \Data\FPA_FOD_20260615.gdb
3. \Data\FPA_FOD_20260615.gpkg
4. \Data\FPA_FOD_20260615.sqlite

All formats contain the same two entities:

i. Fires = table including wildfire data for the period of 1992-2024 compiled from U.S. federal, state, and local reporting systems.
ii. NWCG_UnitIDActive_20200123 = look-up table containing all NWCG identifiers for agency units that were active (i.e., valid) as of 23 January 2020, when the list was downloaded from https://www.nifc.blm.gov/unit_id/Publish.html and used as the source of values available to populate the following fields in the Fires table: NWCG_REPORTING_AGENCY, NWCG_REPORTING_UNIT_ID, and NWCG_REPORTING_UNIT_NAME.

Attributes within each file and entity are the same and described below.
